IndexedDB is the browser’s structured store for larger datasets than localStorage. This article walks through opening a database and creating, reading, updating, and deleting records from a React app.

What is IndexedDB?

IndexedDB is an asynchronous, transactional key-value database in the browser. It holds JavaScript objects, indexes them, and survives reloads. Use it when the data is too large or too structured for localStorage.

Opening a database

const request = indexedDB.open("app", 1);
request.onupgradeneeded = (event) => {
  const db = event.target.result;
  db.createObjectStore("items", { keyPath: "id", autoIncrement: true });
};

Create

Put a record in a readwrite transaction:

function addItem(db, item) {
  return new Promise((resolve, reject) => {
    const tx = db.transaction("items", "readwrite");
    const req = tx.objectStore("items").add(item);
    req.onsuccess = () => resolve(req.result);
    req.onerror = () => reject(req.error);
  });
}

Read

Get one key, or cursor the whole store into React state.

function listItems(db) {
  return new Promise((resolve, reject) => {
    const tx = db.transaction("items", "readonly");
    const req = tx.objectStore("items").getAll();
    req.onsuccess = () => resolve(req.result);
    req.onerror = () => reject(req.error);
  });
}

Update and delete

put replaces a record with the same key. delete removes it. Wrap both in readwrite transactions and refresh the list when the transaction completes.

React

Open the database once in an effect, keep the connection in a ref, and expose add / list / update / delete helpers that set state. Close or leave the connection when the component unmounts; IndexedDB does not need a worker for this CRUD path.
